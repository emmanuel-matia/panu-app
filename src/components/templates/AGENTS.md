## AI templates rules
- AI templates: catalog rows in `ai_templates` (no direct grants) read via `list_templates` (public, no prompt) and `get_template_for_run` (auth); the server rebuilds the prompt from DB fields with `templates-rules.ts` and charges the template's `credit_cost` (`runTemplateMedia`, `startTemplateVideo`). Usage counts are `template_uses` rows written only by service role after a successful creation (idempotent `ref_id`), so rankings stay real. Staff edit via `admin_*_template` RPCs. Bundled covers are `src/assets/templates/<slug>.jpg`; new templates need no code change. Template input photos are temporary `ai-images/<uid>/input-*.jpg` files deleted after use — why: privacy of faces sent to providers.
- Music templates: `settings` carries `vocals` (choice/sung/instrumental, enforced server-side by `resolveVocals`), `lyrics`, `clip`, `demo`; `MusicStudio` drives the flow and `writeSongLyrics` writes lyrics with the text engines. ElevenLabs Music sings lyrics passed in the prompt (`buildSongPrompt`) and `force_instrumental` removes vocals. Vertical clips are rendered in the browser (`music-clip.ts`: beat detection, canvas + MediaRecorder, H.264 MP4 when available else WebM with duration fix) and only uploaded on publish — why: no paid video provider, no server encoding, private media stays on the phone.
